# V17 — intégration des illustrations de lecture

Les illustrations sont intégrées directement dans l'application React.

- La séance Lecture affiche son image propre quand l'unité en fournit une.
- Si une unité ancienne ne possède pas encore de fichier dédié, le moteur choisit automatiquement une illustration réaliste déjà disponible et cohérente avec le thème, au lieu d'afficher une zone vide.
- Le rendu reste dans le design existant de l'application.

Les nouvelles illustrations spécifiques manquantes pourront être ajoutées dans une prochaine passe de génération d'images.
